## Run locally

This site is buildless and has no npm dependencies.

```sh
python -m http.server 8080
```

Open http://localhost:8080/. Use `?lang=en` for English.

GitHub Pages serves the root of the `main` branch. `.nojekyll` disables Jekyll processing.
