# Luan Ribeiro — personal project hub

Personal site cataloguing games, bots, posting automations, official API integrations and public open-source work.

Canonical deployment: https://luandev92.younewx.com/

Mirror: https://luandv92.github.io/projetos/

The AI engineering portfolio remains at https://luandv92.github.io/.

## Run locally

```sh
python -m http.server 8080
```

The project is buildless. `index.html`, `hub.css`, `hub.js` and `assets/` are self-contained. No credentials or private operational code are needed.

## Keep the catalogue accurate

Public games link to their actual hosting/platform. A local bot is labelled as a prototype; a publicly listed Roblox experience is distinct from a browser version. The VORTELYX browser card remains in development until its specific preview or build is located and verified.

App review, account authorization and public publication are distinct states. The Pinterest production approval is documented; TikTok public Direct Post is not presented as approved. Other integrations describe the account authorization and outcomes actually recorded.

Update project records and detail-dialog content together. Do not add credentials, private source paths, account identifiers or claims of audience/learning gains without supporting evidence.
